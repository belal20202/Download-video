# محمّل الفيديو (VideoDL)

تطبيق أندرويد لتحميل الفيديوهات والمقاطع الصوتية من **يوتيوب** و**فيسبوك** و**انستغرام** و**تيك توك**، بعدة جودات، بواجهة عربية. **صُنع في العراق ♥**

- **الإصدار:** 1.1.1
- **آخر تحديث:** 3 نوفمبر 2026

## المميزات

- التعرف على الفيديو من الرابط وعرض عنوانه وصورته ومدته.
- عرض الجودات المتاحة فعلاً لكل فيديو مع الحجم التقريبي.
- تحميل بصيغة MP4 أو استخراج الصوت بصيغة MP3.
- تجهيز الفيديو بصيغة MP4 القياسية لأندرويد (بدون إعادة ترميز) ليعمل في المعرض.
- فحص الملف بعد التحميل للتأكد أنه صالح للتشغيل، وعرض الدقة الفعلية والترميز.
- حفظ الفيديوهات في `Movies/VideoDL` والصوت في `Music/VideoDL`، فتظهر في المعرض وتطبيقات الموسيقى.
- استقبال الروابط مباشرة عبر زر «مشاركة» من التطبيقات الأخرى.
- دعاء قصير مختلف يظهر مع كل عملية تحميل.
- سياسة الخصوصية متاحة داخل التطبيق من أعلى الشاشة.
- شاشة افتتاحية متحركة وواجهة داكنة حديثة.
- زر لتحديث محرك التحميل عند توقف أي موقع عن العمل.

## المتطلبات

- أندرويد 10 (API 29) أو أحدث.
- اتصال بالإنترنت.

## طريقة الاستخدام

1. الصق رابط الفيديو، أو شارك الرابط من التطبيق الأصلي إلى «محمّل الفيديو».
2. اضغط **تعرّف على الفيديو**.
3. اختر الجودة المناسبة.
4. اضغط **تحميل الآن**، ثم **تشغيل الملف** بعد الانتهاء.

## بناء ملف APK عبر GitHub

1. أنشئ مستودعاً جديداً على GitHub وارفع كل ملفات المشروع في الجذر (بجانب مجلد `app`).
2. افتح تبويب **Actions** ثم **Build APK** ثم **Run workflow**. يبدأ البناء تلقائياً عند كل رفع إلى الفرع الرئيسي.
3. بعد انتهاء البناء، نزّل الملف `VideoDL-apk` من قسم **Artifacts**.

يعيد سير العمل محاولة البناء تلقائياً حتى 3 مرات عند حدوث أخطاء شبكة مؤقتة.

## التقنيات المستخدمة

- Kotlin و Jetpack Compose
- [youtubedl-android](https://github.com/yausername/youtubedl-android) (يعتمد على yt-dlp و FFmpeg)
- GitHub Actions لبناء ملف APK

## ملاحظات مهمة

- بعض الفيديوهات الخاصة أو التي تتطلب تسجيل الدخول لا يمكن تحميلها.
- إذا توقف التحميل من موقع معين، اضغط **تحديث محرك التحميل** ثم أعد المحاولة.
- الفيديوهات التي لا تتوفر بترميز متوافق مع أغلب الهواتف قد لا تظهر جودتها في القائمة.

## إخلاء المسؤولية

التطبيق مخصص للاستخدام الشخصي فقط. المستخدم وحده مسؤول عن احترام حقوق الملكية الفكرية وشروط استخدام كل منصة، وعدم تحميل أو نشر محتوى دون إذن صاحبه. التطبيق غير تابع لأي من المنصات المذكورة ولا مرتبط بها.
